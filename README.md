# Pict-au — site officiel

Page commerciale réelle bilingue FR/EN, sans démo cliente et sans faux paiement. Un seul forfait dont le prix n'est pas encore fixé. **Toute la page de vente est visible en même temps dans un unique viewport non déroulant.**

Sur téléphone, la grosse illustration ordinateur/téléphone est cachée pour permettre un vrai titre lisible, les trois fonctions et le forfait sur un seul écran. Les appareils et pictogrammes restent illustratifs sur tablette et ordinateur. Aucune connexion, outil privé ou base Supabase n'est exposé dans cette vitrine.

Site GitHub Pages: https://fredvolks.github.io/Picto-site/

## Prompt maître du projet

Le [prompt maître Pict-au](docs/MASTER_PROMPT.md) reprend les six rôles du modèle universel et consigne les décisions de conception : fond blanc, un seul forfait, vitrine sans démo, une seule vue non déroulante sur PC/tablette/mobile et priorité à l'accessibilité, y compris l'agrandissement du texte.
